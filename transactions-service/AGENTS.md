Ten siempre en cuenta las directivas del README.md de este servicio antes de proponer cualquier cambio. Este servicio maneja datos financieros de usuarios. Toda validación de sesión debe pasar exclusivamente por src/middleware/verifySession.js — no duplicar lógica de JWT en otros módulos. Antes de acceder o devolver una transacción por ID, verificar siempre que transaction.user_id coincide con el usuario autenticado para evitar acceso cruzado. No exponer datos de otros usuarios bajo ninguna circunstancia.
