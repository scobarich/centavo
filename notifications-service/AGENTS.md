Ten siempre en cuenta las directivas del README.md de este servicio antes de proponer cualquier cambio. Este servicio es responsable de procesar eventos de transacciones y generar alertas de sobregasto. Toda validación de sesión de usuario debe pasar exclusivamente por src/middleware/verifySession.js — no duplicar lógica de JWT en otros módulos. Para endpoints de eventos entre servicios, permitir la recepción de transacciones validando que se especifique el userId correspondiente. Antes de acceder, listar o modificar notificaciones por ID, verificar siempre que notification.user_id coincide con el usuario autenticado para evitar acceso cruzado. No exponer alertas ni datos de otros usuarios bajo ninguna circunstancia.
